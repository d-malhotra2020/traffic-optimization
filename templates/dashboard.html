All vehicles, queues, and metrics below are produced by an in-process simulator — there is no live sensor input. The intersection set is a 12×12 grid of synthetic positions for demo purposes. The next commit replaces this with real OpenStreetMap signalized-intersection topology for Downtown San Francisco.

The "optimizer" is rule-based (queue-balancing, pattern-adaptive, efficiency-boost, congestion-relief) — not a trained ML model. The "94% accuracy" and "15% efficiency improvement" numbers shown elsewhere are hardcoded baselines from earlier scaffolding; a measurable Δ from a microsim benchmark is shipping next.
