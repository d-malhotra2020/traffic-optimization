Topology is real. The -- intersections referenced above are real signalized-intersection locations in downtown San Francisco, fetched from OpenStreetMap via the Overpass API (ODbL — © OSM contributors). Snapshot is committed to the repo at data/sf_intersections.json; regenerable with python -m scripts.fetch_osm.

Optimizer Δ is measured. The // optimizer bench panel above runs a Poisson-arrival corridor microsim — adaptive rule-based timing vs fixed-time baseline — and reports the actual throughput / avg-wait delta from -- trials. Results live at data/bench_results.json; regenerable with python -m src.bench.microsim.

Vehicles + queues are simulated. The "active vehicles," queue lengths, and signal-state list come from an in-process queue dynamics model — no live sensor input. The optimizer is rule-based (queue-balancing + pattern-adaptive + efficiency-boost + congestion-relief), not a trained ML model.
